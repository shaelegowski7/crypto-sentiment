What we track for AAPL

Every 15 minutes, SentimentFX collects the latest Apple Inc. news from major financial publishers and RSS feeds, then scores each headline using FinBERT — a transformer model fine-tuned on financial text. The output is a sentiment score on a 0–100 scale, where 50 is neutral, and we plot the daily average against AAPL price so you can see how news flow moves with the market.

Apple Inc. is the largest US consumer-tech company; iPhone cycle and services revenue dominate headlines, which makes AAPL an especially useful ticker for sentiment-driven analysis. Our pipeline pulls from Yahoo Finance and other major financial newswires, deduplicates by URL, and only stores headlines whose title actually mentions AAPL or a recognised alias.

Sentiment vs price correlation

The dashboard plots AAPL sentiment against price on a single chart, with a rolling 180-day correlation analysis that reports Pearson r, p-value, a 95% confidence interval and a plain-English strength label (strong / weak / inconclusive). You can also pull the raw correlation via the public API endpoint /v1/correlation/AAPL.

Developer access

All AAPL sentiment, price and correlation data is available via the SentimentFX REST API. Generate a key on the developer portal, then call GET /v1/sentiment/AAPL with an X-API-Key header. Free tier included, metered billing beyond that.

AAPL sentiment FAQ

How is AAPL sentiment calculated?
SentimentFX scrapes Apple Inc. news headlines from major financial outlets every 15 minutes and scores each one with FinBERT, a finance-tuned transformer model. The score is the model's positive probability minus its negative probability, presented on a 0–100 scale where 50 is neutral, below 50 is bearish and above 50 is bullish.
How often is AAPL sentiment data updated?
The scraper runs every 15 minutes, pulling new AAPL headlines from Yahoo Finance RSS feeds. New sentiment scores are usually live within 1–2 minutes of scrape completion.
Can I correlate AAPL sentiment with its price?
Yes — the SentimentFX dashboard plots AAPL sentiment against price on the same chart, and the correlation endpoint returns a Pearson r value, 95% confidence interval and strength label over a rolling 180-day window. You can also pull this via the public REST API at developers.sentimentfx.org.
Is AAPL sentiment data available via API?
Yes. The SentimentFX public API exposes /v1/sentiment/AAPL, /v1/summary/AAPL, /v1/prices/AAPL and /v1/correlation/AAPL endpoints. Authentication is via X-API-Key header. See the developer portal for full reference.
