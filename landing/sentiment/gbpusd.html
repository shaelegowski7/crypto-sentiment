What we track for GBP/USD

Every hour, SentimentFX collects the latest British Pound / US Dollar news from major financial publishers and RSS feeds, then scores each headline using FinBERT — a transformer model fine-tuned on financial text. The output is a sentiment score between -1 (very bearish) and +1 (very bullish), and we plot the daily average against GBP/USD price so you can see how news flow moves with the market.

British Pound / US Dollar is the cable, sensitive to Bank of England decisions and UK macro headlines, which makes GBP/USD an especially useful ticker for sentiment-driven analysis. Our pipeline pulls from FXStreet, ForexLive, DailyFX, ActionForex and Reddit alongside GNews search results, deduplicates by URL, and only stores headlines whose title actually mentions GBP/USD or a recognised alias.

Sentiment vs price correlation

The dashboard plots GBP/USD sentiment against price on a single chart, with a rolling 180-day correlation analysis that reports Pearson r, p-value, a 95% confidence interval and a plain-English strength label (strong / weak / inconclusive). You can also pull the raw correlation via the public API endpoint /v1/correlation/GBPUSD.

Developer access

All GBP/USD sentiment, price and correlation data is available via the SentimentFX REST API. Generate a key on the developer portal, then call GET /v1/sentiment/GBPUSD with an X-API-Key header. Free tier included, metered billing beyond that.

GBP/USD sentiment FAQ

How is GBP/USD sentiment calculated?
SentimentFX scrapes British Pound / US Dollar news headlines from major financial outlets every hour and scores each one with FinBERT, a finance-tuned transformer model. The score is the model's positive probability minus negative probability, giving a value between -1 (very bearish) and +1 (very bullish).
How often is GBP/USD sentiment data updated?
The scraper runs every hour, pulling new GBP/USD headlines from GNews and forex RSS feeds (FXStreet, ForexLive, DailyFX). New sentiment scores are usually live within 1–2 minutes of scrape completion.
Can I correlate GBP/USD sentiment with its price?
Yes — the SentimentFX dashboard plots GBP/USD sentiment against price on the same chart, and the correlation endpoint returns a Pearson r value, 95% confidence interval and strength label over a rolling 180-day window. You can also pull this via the public REST API at developers.sentimentfx.org.
Is GBP/USD sentiment data available via API?
Yes. The SentimentFX public API exposes /v1/sentiment/GBPUSD, /v1/summary/GBPUSD, /v1/prices/GBPUSD and /v1/correlation/GBPUSD endpoints. Authentication is via X-API-Key header. See the developer portal for full reference.
