API Reference

BASE URL: HTTPS://CRYPTO-SENTIMENT-PRODUCTION.UP.RAILWAY.APP

Authentication

All API endpoints require an API key passed as a request header. Generate your key on the dashboard.

Include your API key in every request using the X-API-Key header.
Example Request
# Curl
curl https://crypto-sentiment-production.up.railway.app/v1/sentiment/BTC \
  -H "X-API-Key: sfx_your_api_key_here"

# Python
import requests
res = requests.get(
    "https://crypto-sentiment-production.up.railway.app/v1/sentiment/BTC",
    headers={"X-API-Key": "sfx_your_api_key_here"}
)

# JavaScript
const res = await fetch(
    "https://crypto-sentiment-production.up.railway.app/v1/sentiment/BTC",
    { headers: { "X-API-Key": "sfx_your_api_key_here" } }
)

Sentiment

GET /v1/sentiment/{ticker}

Returns the 50 most recent sentiment-scored headlines for the specified ticker, ordered by date descending.

ParameterTypeDescription
tickerstringBTC, ETH, SOL, XRP, or DOGE
Response
{
  "ticker": "BTC",
  "data": [
    {
      "date": "2026-04-27T12:00:00",
      "title": "Bitcoin hits new yearly high amid ETF inflows",
      "source": "CoinDesk",
      "sentiment_score": 0.6821,
      "sentiment_label": "positive"
    }
  ]
}

Prices

GET /v1/prices/{ticker}

Returns the last 90 days of daily closing prices in GBP for the specified ticker.

ParameterTypeDescription
tickerstringBTC, ETH, SOL, XRP, or DOGE
Response
{
  "ticker": "BTC",
  "data": [
    {
      "date": "2026-04-27T00:00:00",
      "close_price_gbp": 72841.50,
      "volume": 18294830293.0
    }
  ]
}

Correlation

GET /v1/correlation/{ticker}

Returns Pearson correlation between sentiment and price returns across lag periods of 0–7 days. Useful for identifying predictive signal timing.

ParameterTypeDescription
tickerstringBTC, ETH, SOL, XRP, or DOGE
Response
{
  "ticker": "BTC",
  "best_lag_days": 2,
  "correlation": 0.412,
  "all_lags": {
    "0": 0.121,
    "1": 0.287,
    "2": 0.412,
    "3": 0.198
  }
}
